# 隐私与数据

## 哪些内容会离开设备

编辑文字、选择模板和复制由本机处理。点击 AI 微调、重新生成、追问或生成可复用模板时，Talis 会将完成该操作所需的输入、近期上下文或追问回答发送给你选择的模型服务，并使用你的 API Key 鉴权。

这些请求由 App 直接发送到相应供应商。桌面版未接入 Talis 账号服务器、遥测或崩溃上报服务。模型供应商按其自身政策处理收到的请求。

## 本机保存

个人模板和系统模板修改保存在 `~/Library/Application Support/Talis` 中。模型选择等设置保存在应用偏好设置中。当前编辑历史保存在当前运行的应用状态里。

API Key 按供应商分别保存在 macOS Keychain，不写入偏好设置或新建明文配置。设置页的输入框会遮住新输入的密钥，也不会回显已保存的值。切换供应商会清空尚未提交的输入。保存失败会明确提示，原有密钥不会因先删除再写入而丢失。

旧版升级时，先按原有优先顺序读取旧配置。确认写入 Keychain 并读回成功后，才移除活动偏好设置及配置文件中的明文 Key。旧来源中不同的 Key 会作为对应供应商的恢复项保存在 Keychain，不会自动用于其他供应商。任何迁移失败都会保留尚未清除的旧输入并显示错误。

在设置中点击“移除 API Key”，只会删除所选供应商的密钥及对应旧恢复项，其他供应商保持不变。完成迁移后，不会从旧配置自动恢复已移除的密钥。你自行保留的历史备份仍可能含有旧配置，应按私人材料管理，不要放入公开仓库或反馈附件。

## 分享和反馈

复制后的文字由你决定发给哪个工具。反馈问题时，请提供发生问题的操作、App 版本、macOS 版本和经过脱敏的输入。移除 API Key、客户材料及个人敏感信息。
