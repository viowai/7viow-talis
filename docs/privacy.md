## 哪些内容会离开设备

编辑文字、选择模板和复制由本机处理。点击 微调、重构、追问或生成可复用模板时，Talis 会将完成该操作所需的输入、近期上下文或追问回答发送给你选择的模型服务。API Key 厂商使用对应密钥鉴权；订阅共享使用本机已经登录的对应 AI 产品订阅。

API Key 请求由 App 直接发送到你选择的厂商接口；使用自定义接口时，会发送到所填地址。订阅共享通过本机受信任的共享网关发送请求；Talis 不读取或保存任何产品的 OAuth token。桌面版未接入 Talis 账号服务器、遥测或崩溃上报服务。模型供应商按其自身政策处理收到的请求。

为了跟进模型版本，Talis 会在使用 AI 时查询所选厂商的模型 API 或官方公开模型目录。公开目录请求不携带 API Key、输入文字或历史上下文；需要鉴权的模型列表 API 只使用所选厂商的 Key。目录结果会在本机缓存，避免反复请求。

点击“停止”会取消本机等待并忽略晚到结果。已经发给厂商的请求可能已经开始处理，停止不会撤回已发送的内容。

## 本机保存

个人模板和系统模板修改保存在 `~/Library/Application Support/Talis` 中。厂商、服务接口与已解析的模型 ID、目录刷新时间保存在应用偏好设置中。普通草稿和当前编辑历史只保存在当前应用进程内：Esc、关闭或快捷键收起会结束当前快速会话，最近一次内容可在同一进程内显式恢复；完全退出 App 后不会自动恢复。

API Key 按供应商分别保存在 macOS 钥匙串中，不写入偏好设置或新建明文配置。设置页的输入框会遮住新输入的密钥，也不会回显已保存的值。切换供应商会清空尚未提交的输入。保存失败会明确提示，原有密钥不会因先删除再写入而丢失。

旧版升级时，先按原有优先顺序读取旧配置。确认写入 macOS 钥匙串并读回成功后，才移除活动偏好设置及配置文件中的明文 Key。旧来源中不同的 Key 会作为对应供应商的恢复项保存在 macOS 钥匙串中，不会自动用于其他供应商。任何迁移失败都会保留尚未清除的旧输入并显示错误。

在设置中点击“移除 API Key…”并确认后，只会删除所选供应商的密钥及对应旧恢复项，其他供应商保持不变。完成迁移后，不会从旧配置自动恢复已移除的密钥。你自行保留的历史备份仍可能含有旧配置，应按私人材料管理，不要放入公开仓库或反馈附件。

## 分享和反馈

复制后的文字由你决定发给哪个工具。反馈问题时，请提供发生问题的操作、App 版本、macOS 版本和经过脱敏的输入。移除 API Key、客户材料及个人敏感信息。
