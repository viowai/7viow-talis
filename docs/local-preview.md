# Talis

## 阅读指引

供本机试用。打开 `/Applications/Talis.app`，按实际任务检查输入、微调／重构／追问、继续修改和复制。反馈给出操作、预期与实际结果即可。

唤起快捷键为 **Option+Shift+Space**。旧版应用已归档，现用模板、设置和密钥保持原样。

从并列的“微调、重构、追问”中选择一种。结果在原内容框显示，右侧突出“复制 Prompt ⌘↵”；需要继续修改时，再选一种模式即可。运行状态只显示一处，停止后保留原文。追问以附着当前编辑窗口的面板呈现；主窗口先扩展容纳面板，结束后恢复紧凑布局。

“修改记录 · N 轮”打开独立窗口，按轮次查看完整输入与结果。记录保留本次编辑会话，AI 处理参考最近 3 轮。

模板卡片点击只选中，应用按钮随选中项显示。空正文时为“应用”，已有正文时为琥珀色选择态与“替换”；应用后可按 ⌘Z 撤销。从“模板”菜单打开“模板中心”，可“存为新”和有来源时的“更新”。清空留在内容区。

【待填写内容】以紫色高亮；括号、冒号、名字和正文都能自由编辑或删除，不会自动补回。Tab 跳至下一处，Shift+Tab 返回上一处；复制、保存与撤销保留实际文字。只有存在标记时，左下角才显示两行说明。Esc、关闭或快捷键收起会结束当前快速会话，下次唤起为空白；可从主界面的“恢复上次草稿”或 `Prompt > 恢复上次草稿` 找回最近一次正文和修改记录。完全退出后不会自动恢复。

菜单栏单击 T 打开或收起 Talis；右击 T 显示精简命令菜单。

## 本机更新

进行可见调试或截图时，Codex 自行选择当前不显示用户 ChatGPT 页面的桌面，使用“独立工作窗口”继续同一会话。完成后在该桌面切回“快速浮窗”验收，再隐藏 Talis。已有桌面即可。

先保留正在编辑的文字并退出 Talis，然后在源码目录执行：

```bash
bash scripts/install_preview_app.sh
```

更新会保留模板、设置与密钥。旧应用包保存在私有备份目录中，位于 `Backups/Archives.noindex/<timestamp>/AppBundle.zip`，恢复由维护入口处理。GitHub 与 viow.ai 发布等待试用后的明确指令。
