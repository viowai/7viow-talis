# AI 服务设置

[简体中文](ai-services.md) | [English](ai-services.en.md)

点击主窗口右上角齿轮打开“AI 服务设置”，也可从应用菜单打开或按 `Command + ,`。

1. 选择认证方式：`API Key` 或 `订阅共享`。
2. 在 API Key 组选择原有模型厂商及服务区域；订阅共享组会列出本机共享网关当前提供的全部服务。新安装默认是 API Key 组的 DeepSeek。
3. 点击“获取 API Key”打开该厂商控制台，创建或查看自己的密钥；在 Talis 中输入并保存。已有密钥不显示，留空保存会保留。
4. 回到输入窗口使用 微调、重构、追问或生成模板。

需要业务空间专属 URL 或兼容服务时，在“服务区域”中选择“自定义接口”，填写控制台提供的完整 HTTPS 基础地址。该地址会接收你的 API Key 和处理任务所需的内容；无需填写具体模型名。阿里云新业务空间的专属域名可在这里配置。

订阅共享不需要填写 API Key。Talis 从 `127.0.0.1:3425/v1/models` 读取本机网关当前可共享的服务，按服务分组并选择当前文本模型；不会读取、复制或保存各产品的登录文件或 OAuth token。网关不可用时只保留可验证的 Codex fallback。

## 支持的厂商

API Key 组：DeepSeek、Kimi、MiniMax、OpenAI API、Anthropic、Google、xAI、腾讯混元、百度文心、阿里通义、字节豆包、智谱 GLM。订阅共享组按本机网关实际暴露的服务动态列出；当前本机验证可见 `Codex`、`OpenAI`、`Kimi Work` 和 `DeepSeek`。实际可见项和权益仍以本机网关与服务商账号状态为准。

## 模型自动跟进

Talis 会优先使用厂商官方持续更新的模型别名。没有相应别名的厂商，在使用 AI 时从模型列表或官方公开目录中选择适合文本任务的当前正式版本，最多每 24 小时更新一次目录。选择限定在所选厂商的效率或常规系列，避开预览、实验及高价加速版本。

目录暂时无法访问时继续使用已保留的选择。模型明确停用时，会尝试刷新目录并寻找同厂商替代；替代结果会在缓存有效期内继续用于后续操作，重启 App 也会保留。密钥、余额、限额或网络错误会直接提示，修复后可重试。Codex 订阅不可用时不会自动切回 OpenAI API Key，避免静默产生 API 费用。厂商更改接口、模型命名体系或系列定位时，仍可能需要更新 App。

## 更新与密钥保留

更新 App 保留原有模板、设置及 macOS 钥匙串中的 API Key。切换厂商会清空未保存的新密钥输入；每家厂商独立保存。打开设置或切换厂商仅检查钥匙串项是否存在，不为显示状态读取密钥正文；真正使用、保存或迁移密钥时，macOS 仍可能请求授权。要替换密钥，输入新值后保存；点击“移除 API Key…”后，会先显示所选厂商并要求确认；仅影响当前厂商。
