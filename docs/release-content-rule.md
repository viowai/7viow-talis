# Release content language rule / 发布内容语言规则

Public release content for Talis uses Simplified Chinese and English.
Talis 的公开发布内容使用简体中文和 English。

- Publish both languages together. Do not translate only the headline.
- 中英文一起发布，不只翻译标题。
- Keep product behavior, platform support, download, signing and publication status factual. Draft, candidate and published are different states.
- 产品行为、平台支持、下载、签名和发布状态必须基于事实；草稿、候选和已发布是不同状态。
- Do not translate model instructions, template identifiers, user-authored content or provider names that are product identifiers.
- 不批量翻译模型指令、模板 ID、用户正文或作为产品标识的服务名称。
- Short-form copy may use parallel Chinese and English versions. A one-post bilingual version is optional, not a requirement to exceed a channel's length limit.
- 短帖可以使用并列的中英版本；是否放在同一条帖子中，以不超出平台长度为前提。
- Repository and website documentation may provide linked Chinese and English documents when full bilingual pages would be harder to read.
- 仓库和网站文档可以提供互相链接的中英文版本，以避免单页过长。
- Review the Chinese and English copy, public file scope and media before any publication.
- 每次公开发布前复核中英文内容、公开文件范围和媒体。

This is a content-maintenance rule. It does not authorize a push, upload, deployment, message or public release.
这是内容维护规则，不授权 push、上传、部署、发送或公开发布。
